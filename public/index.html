  • Do not call a pick “90% likely” just because it won 9 of the last 10.

A 9/10 historical hit rate is a small sample, not proof that the next event has a 90% chance of winning.

Connection status & limitations

Booking-code lookup runs through the included server to avoid browser cross-origin restrictions. It uses an undocumented SportyBet web endpoint, not an official public developer API, so it can stop working if SportyBet changes its service.

Loading a booking code retrieves the slip; it does not automatically verify historical results or calculate reliable live predictions. Those need a separate results-data integration.
